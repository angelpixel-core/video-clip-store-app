# Billing Presentation

Presentation turns billing data into a deliverable shape.

## Contents

- `html/` - ERB, ViewComponent, partial, or document renderers.
- `json/` - JSON serializers or presenters.
- `stream/` - Turbo Stream, SSE, websocket payload, or realtime output.
- `binary/` - PDFs, images, or other byte-oriented outputs.

## Rule

- Presentation formats data; it does not decide billing behavior.
